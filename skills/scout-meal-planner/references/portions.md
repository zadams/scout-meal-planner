# Portion Reference (per person, one meal)

Kids = Cub Scout age (5–10) and siblings. Bump everything ~20% after
strenuous activity (trail run, long hike).

| Item | Kid | Adult | Notes |
|---|---|---|---|
| Sandwiches (lunch) | 1.25 | 1.75 | Younger kids often eat 1; older kids/adults 2 |
| Bread | 2 slices/sandwich | same | ~20 usable slices per 20–24 oz loaf |
| Peanut butter / SunButter | 1.25 oz/sandwich | same | ≈2.5 Tbsp; kids spread thick |
| Jelly | 0.8 oz/sandwich | same | ≈1 heaping Tbsp |
| Deli turkey | 2.5 oz/sandwich | same | 1 lb ≈ 6 sandwiches |
| Sliced cheese | 1.5 slices/sandwich | same | Veg sandwich: 2 slices |
| Hummus (veg sandwich) | 1 oz/sandwich | same | Plan 1.6 veg sandwiches per vegetarian, +15% |
| Lettuce (pre-washed) | 1 leaf/sandwich | same | Veg sandwiches + ~half of deli sandwiches |
| Chips | 1 snack bag | 1 bag | +10% buffer |
| Whole fruit | 1 piece | 1 piece | +25% buffer; clementines ~2 = 1 serving |
| Water | 1–2 bottles | 2 bottles | 2+ each after exercise or heat |
| Hot dogs | 1.5 | 2 | For reference on other meals |
| Burgers (¼ lb) | 1 | 1.5 | |
| Pancakes (4") | 3 | 4 | ~1 cup dry mix per 7–8 pancakes |
| Scrambled eggs | 1.5 eggs | 2.5 eggs | |
| Pasta (dry) | 3 oz | 4 oz | |
| Plates / napkins | 1.2 / 3 | same | |

## Buffers
- Shelf-stable: +15–20% (bread, PB, jelly, chips).
- Perishable: +5–10% (deli meat, cheese, dairy).
- Fruit: +25% (it's the side people take seconds of, and it keeps).
