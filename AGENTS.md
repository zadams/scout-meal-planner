# Agent Instructions

This repo plans group camping meals.

- The planning workflow lives in `skills/scout-meal-planner/SKILL.md`. For any
  request to plan, scale, or shop for a group/camp meal, read that file and
  follow it, even if your harness doesn't auto-load skills.
- Paths inside the skill are relative to `skills/scout-meal-planner/`.
- Event profiles and finished plans go in `plans/`.
- Only `python3` (standard library) is required.
